# AskVela Dream Interpretation — Phase 8 Contract

Dream interpretation is a source-grounded reflective reading, not diagnosis, therapy, prediction, or a fixed symbol dictionary.

Runtime provenance uses verified public-domain historical psychology texts: Sigmund Freud, The Interpretation of Dreams (Brill translation, Macmillan 1913, Project Gutenberg 66048) and C. G. Jung, Psychology of the Unconscious (Hinkle translation, 1916, Project Gutenberg 65903).

These books are historical interpretive frameworks rather than modern clinical consensus.

## Evidence rules
- Prefer the dreamer's own associations, waking context, and emotional response over universal symbol lookup.
- Separate remembered dream content from proposed interpretation.
- Treat condensation, displacement, recurring motifs, and symbolic parallels as hypotheses rather than facts.
- Never claim that a dream proves a diagnosis, future event, supernatural message, or another person's intention.
- Every reading exposes the source principles actually used.

## Pipeline
Dream text -> structured extraction -> deterministic evidence selection -> Vela contextual synthesis -> references and reflection prompts.

## History
Dream history is private, account-scoped, protected by RLS, and follows the same 365-day retention policy as Tarot and Astrology.
